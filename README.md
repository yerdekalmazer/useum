# useum — Deneyim bir ilişkidir

> Bir ürün deneyimi tek seferde verilen sabit bir hüküm değil, zaman içinde oluşan ve değişebilen bir ilişkidir.

useum'u anlatan kaydırmalı 3B hikâye sayfası: hüküm → iddia → zaman → bakışlar → salon → ortak hafıza → arama.

- Figürler kodla modellendi (`model/`: SDF parçaları → surface nets → `modeller/*.bin`). Yeniden üretmek için: `node model/uret.mjs` ve `node model/uret.mjs --dusuk`
- Tüm metinler `veri.js` içinde.
- Yerelde açmak için: `python3 -m http.server` → http://localhost:8000
